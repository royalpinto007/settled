Connect your application

POST normalized lifecycle events to /api/traces. Record the request, 402 challenge, verification, settlement, and delivery in order. Mark unattempted stages as skipped. 

await fetch('http://127.0.0.1:4402/api/traces', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ request, payment, events })
});

Use examples/capture.mjs in the repository for a complete, runnable example. Only send redacted metadata. Never capture keys, payment payloads, authorization headers or query strings.
